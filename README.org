* Tiled

A text editor, windows manager, IDE, browser and agentic tool written
in [[https://github.com/jtimon/til][til]] language.

Inspired by [[https://www.gnu.org/software/emacs/][Emacs]] and [[https://neovim.io/][Neovim]] (editing), [[https://github.com/i3/i3][i3]] (window management),
[[http://conkeror.org/][Conkeror]] (browsing), [[https://www.gnu.org/software/screen/][GNU Screen]] and [[https://github.com/tmux/tmux][tmux]] (persistent sessions),
[[https://docs.xfce.org/apps/xfce4-terminal/start][xfce4-terminal]] and [[https://ghostty.org/][Ghostty]] (terminal UX), and [[https://github.com/anomalyco/opencode][OpenCode]] (agents).

** Getting started

Uses installed Til with natural core/std imports (#413).
See the generated [[file:doc/til-dependency.org][Til build dependency]].
See [[file:doc/build.org][build requirements and details]].
From the repository root:

#+begin_src sh
./make.til
./bin/tiled
./bin/tilminal
#+end_src

The executable Til build script uses installed =til run=; no GNU Make or
compiler bootstrap is needed here. =./make.til clean= removes build outputs
and =tmp/=, preserving reference repositories under =.inspirations/=.

Tiled starts fresh by default. Opt in to saving/restoring opened files and tabs
in =~/.tiled/init.til=; see [[file:doc/sessions.org][saved sessions]]. The working
config [[file:defaults/init.til][defaults/init.til]] includes the settings to enable it.
Use =--no-session= to bypass persistence for one launch.
