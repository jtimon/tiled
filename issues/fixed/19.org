** FIXED #19 Run retained guest text commands in the live editor

Implemented =tiled_text_command(name, symbol)= and a separate typed guest
registry. Init registrations are validated before applying bindings/opening the
GUI; duplicate guest names replace earlier registrations, while empty/built-in
names and bad symbols/signatures fail startup. Partial handles and staged
settings are cleared on failure. The main process retains the VM through the
editor loop, destroying command handles before the VM.

Keybindings and M-x invoke the same retained callbacks. Discovery and dispatch
require a nonempty text region and reject terminal/minibuffer contexts. Results
use the ordinary replacement/undo path; guest errors leave text/selection intact,
display status feedback, and allow subsequent commands. Captures remain live.

  =command_discovery= also passed.
